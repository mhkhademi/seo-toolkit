# جعبه‌ابزار سئو

دایرکتوری فارسی و راست‌به‌چپِ ابزارهای روزمرهٔ سئو، محتوا و تبلیغات — بدون هیچ وابستگی، فقط HTML/CSS/JS. آفلاین و نصب‌پذیر به‌صورت اپ (PWA).

## امکانات

- جستجوی فارسی‌پسند با نرمال‌سازی (نیم‌فاصله، ي/ك، أ/إ/آ …) و هایلایت نتایج
- فیلتر دسته‌بندی، رایگان و ستاره‌دارها + مرتب‌سازی پیش‌فرض/الفبایی/پرکاربرد
- علاقه‌مندی‌ها و آمار استفاده در localStorage؛ تم تیره/روشن
- آیکون‌های محلی برای همهٔ ابزارها + آیکون پیش‌فرض در صورت خطای بارگذاری
- ناوبری با کیبورد: `/` یا `Ctrl+K` برای جستجو، `Enter` اولین نتیجه، `↑↓` جابجایی
- صفر درخواست خارجی در زمان اجرا — فونت محلی وزیرمتن

## اجرا

بدون بیلد لازم است؛ کافی است یک سرور ساده بالا بیاورید:

```bash
python -m http.server 8000
```

و `http://localhost:8000` را باز کنید. (باز کردن مستقیم `index.html` هم با fallback داخلی کار می‌کند.)

## نگهداری داده

`tools.json` منبع اصلی داده است. پس از هر ویرایش:

```bash
PYTHONUTF8=1 python maintain.py sync    # بازسازی data.js + اعتبارسنجی
PYTHONUTF8=1 python maintain.py icons   # گزارش ابزارهای بدون آیکون محلی
PYTHONUTF8=1 python maintain.py links   # بررسی لینک‌ها
```

اسکریپت `download_icons.py` آیکون‌های محلی را دانلود/می‌سازد و مانیفست `icons.json` را به‌روز می‌کند.

## ساختار پروژه

```
index.html / style.css / script.js    اپلیکیشن
tools.json / data.js                  دادهٔ ابزارها (data.js خروجی sync)
icons/ + icons.json                   آیکون‌های محلی + مانیفست
manifest.webmanifest / sw.js          PWA و حالت آفلاین
maintain.py / download_icons.py       اسکریپت‌های نگهداری
fonts/ + fonts.css                    فونت محلی وزیرمتن
```
