# جعبه‌ابزار سئو (SEO Toolbox) — نسخه ۲.۰ 🚀

دایرکتوری فارسی و جعبه‌ابزار آنلاین و جامع سئو، تولید محتوا و دیجیتال مارکتینگ — کاملاً بدون وابستگی خارجی (۱۰۰٪ Vanilla JS / CSS / HTML)، فوق‌العاده سریع، آفلاین و نصب‌پذیر به‌صورت وب‌اپلیکیشن پیش‌رونده (PWA).

---

## ⚡ تغییرات بزرگ نسخه ۲.۰ (What's New in v2.0)

نسخه ۲.۰ یک بازطراحی و جهش اساسی برای جعبه‌ابزار سئو است که پروژه را از یک دایرکتوری ساده به یک پلتفرم کامل و همه‌فن‌حریف ابزارهای کاربردی تبدیل کرده است:

1. **اضافه شدن ۱۰ ابزار آنلاین و تخصصی سئو در تب اختصاصی:**
   - **شبیه‌ساز زنده نتایج گوگل (SERP Simulator):** پیش‌نمایش بلادرنگ عنوان و توضیحات متا در ابعاد دسکتاپ و موبایل به همراه سنجش پیکسل، کاراکتر و تولید کد HTML.
   - **اسکیما ساز تعاملی JSON-LD:** تولید اسکیماهای استاندارد FAQ، مقاله (Article)، کسب‌وکار محلی (LocalBusiness)، محصول (Product)، رویداد، دستورالعمل (HowTo) و ساختار Breadcrumb با تست مستقیم در گوگل.
   - **سازنده فایل Robots.txt:** تعریف سریع قوانین User-Agent، مسیرهای Allow/Disallow، آدرس Sitemap و قالب‌های آماده وردپرس و فروشگاهی.
   - **سازنده نقشه سایت (XML Sitemap Generator):** تبدیل گروهی آدرس‌ها به نقشه سایت استاندارد با فرکانس تغییر، اولویت و دانلود مستقیم فایل.
   - **آنالیزور و سئوی محتوا (Content SEO Analyzer):** شمارش زنده کلمات، کاراکترها، جملات، تخمین زمان مطالعه، چگالی کلمات کلیدی، استخراج هدینگ‌ها (H1-H6) و تحلیل خوانایی متن فارسی بدون کلمات توقف.
   - **سازنده پیشرفته UTM و بارکد QR:** تولید لینک‌های ردیابی کمپین گوگل آنالیتیکس همراه با پیش‌تنظیم‌های آماده، تاریخچه مرورگر و دانلود بارکد اختصاصی QR.
   - **سازنده ریدایرکت‌های ۳۰۱ و قوانین سرور:** تولید کدهای ریدایرکت برای وب‌سرورهای Apache (.htaccess)، Nginx و Cloudflare با تنظیمات HTTPS، WWW و اسلش پایانی.
   - **ترکیب کلمات کلیدی (Keyword Mixer):** ترکیب هوشمند کلمات در ۳ ستون با حالت‌های مچ‌تایپ گوگل ادز (Broad, Phrase, Exact).
   - **پیش‌نمایش کارت‌های شبکه‌های اجتماعی (Social Share Previewer):** شبیه‌ساز واقعی کارت لینک در تلگرام، توییتر (X)، واتس‌اپ و لینکدین با تولید خودکار تگ‌های Open Graph و Twitter Cards.
   - **چک‌لیست ۲۴گانه جامع ممیزی سئو (SEO Audit Checklist):** دسته‌بندی ممیزی تکنیکال، محتوا، Core Web Vitals و ایندکس همراه با فیلتر وضعیت، چاپ نسخه PDF و خروجی گزارش متنی.

2. **سیستم نصب PWA و آفلاین کامل:**
   - امکان نصب مستقل برنامه روی تسک‌بار ویندوز، داک مک، صفحه اصلی اندروید و iOS.
   - مودال راهنمای گام‌به‌گام نصب برای تمام مرورگرها و پلتفرم‌ها.
   - استراتژی کش بهینه‌شده آفلاین در سرویس‌ورکر (`sw.js`) بدون وابستگی به اینترنت.

3. **هویت بصری جدید و استاندارد سئو:**
   - پالت رنگی حرفه‌ای سئو متشکل از **آبی تکنیکال و تحلیلی** (Tech Blue) و **نارنجی پرانرژی رشد** (Action Orange).
   - هماهنگی و شارپنس کامل کنتراست متن در هر دو حالت تیره (Dark Mode) و روشن (Light Mode) مطابق استاندارد WCAG AAA.

4. **معماری فایل تمیز و ماژولار:**
   - تفکیک فایل‌های پایگاه داده و مانیفست‌ها در پوشه `data/`.
   - انتقال اسکریپت‌های اتوماسیون به پوشه `scripts/`.
   - ادغام فونت‌های بومی در `style.css` و یکپارچه‌سازی وظایف نگهداری و بیلد در موتور `maintain.py`.

5. **امکانات تعاملی جدید کاربران:**
   - فرم تعاملی پیشنهاد و ثبت ابزارهای سئو با ذخیره محلی و خروجی فرمت JSON استاندارد.
   - سیستم حمایت و تبلیغات هدفمند (Sponsorship) برای معرفی برندها و ابزارهای سئوکاران.

> 📢 **آپدیت‌های خفنی تو راهه!**  
> تیم در حال آماده‌سازی قابلیت‌های هیجان‌انگیزتر شامل تحلیل عمیق‌تر آن‌پیج، ابزارهای تحلیلی بیشتر و امکانات پیشرفته‌تر برای جامعه متخصصین سئو و وبمستران است. با ما همراه باشید!

## 🌟 امکانات کلی دایرکتوری

- **جستجوی هوشمند فارسی:** پشتیبانی از نیم‌فاصله، تمام حالات ي/ك و حروف عربی با هایلایت آنی.
- **فیلترهای کاربردی سریع:** تفکیک بر اساس رایگان، بدون فیلترشکن (No VPN)، خرید ریالی، دسته‌بندی موضوعی و ابزارهای ستاره‌دار.
- **شخصی‌سازی محلی:** ثبت علاقه‌مندی‌ها و مرتب‌سازی بر اساس پرکاربردترین‌ها در localStorage بدون نیاز به ثبت‌نام.
- **سرعت فوق‌العاده:** صفر درخواست خارجی در زمان اجرا، بدون کتابخانه‌های سنگین خارجی و با کمترین بار پردازشی.

## 🚀 نحوه اجرا

پروژه بدون نیاز به بیلد یا پکیج‌منیجر اجرا می‌شود؛ کافی است یک سرور محلی ساده اجرا کنید:

```bash
python -m http.server 8000
```
سپس آدرس `http://localhost:8000` را باز کنید. (یا حتی فایل `index.html` را مستقیماً در مرورگر اجرا کنید).

## 🛠️ نگهداری و همگام‌سازی خودکار

فایل `data/tools.json` منبع اصلی داده‌های ابزارها است. پس از هر تغییر در دیتابیس، دستور تک‌خطی زیر تمام مراحل را به صورت خودکار انجام می‌دهد:

```bash
python maintain.py sync
```

این دستور به صورت خودکار:
1. داده‌های ابزارها را اعتبارسنجی و تکراری‌ها را بررسی می‌کند.
2. نسخه آفلاین `data/data.js` را تولید می‌کند.
3. متاداده‌های JSON-LD را درون `index.html` به‌روزرسانی می‌کند.
4. تاریخ `lastmod` نقشه سایت `sitemap.xml` را آپدیت می‌کند.
5. برای شکستن کش مرورگرها، هش نسخه محتوا (`?v=...`) را به فایل‌های استاتیک تزریق می‌کند.

سایر دستورات:
```bash
python maintain.py icons     # بررسی وضعیت و گزارش ابزارهای فاقد آیکون محلی
python maintain.py links     # تست سلامت لینک‌ها و بررسی کدهای وضعیت HTTP
python maintain.py all       # اجرای کامل تمام تست‌ها
```

│   ├── [domain].png         # آیکون اختصاصی هر سرویس
│   ├── default.png          # آیکون پیش‌فرض جایگزین
│   ├── icon-192.png         # آیکون PWA موبایل
│   ├── icon-512.png         # آیکون PWA دسکتاپ
